# PR / issue style

- Branch: `security/vulnbot`.
- Label: `vulnbot` (create if missing).
- Commit: `security(vulnbot): …`
- PR title: same style.
- PR body: findings fixed, linked issues, verify commands + result,
  quarantine/security-exception notes for dep bumps.
- Issues: title keys per `findings.md`; label `vulnbot`.
- No unrelated refactors.
